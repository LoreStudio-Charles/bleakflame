# Playtest checklist — abilities + energy (fresh game)

Everything below is BUILT and passing `tools/test_abilities.gd`, but **none of it
has ever been played.** The tests prove the twelve modules are wired and costed;
only the playtest says whether they're any fun.

## Reaching an ability (the fast path)

A fresh pilot has no commission, no standing and no credits, so the modules are
behind three gates. In a **debug build** all three open in about a minute:

1. **`** (grave) → +10,000c. Press it a few times.
2. Dock → **Pilot tab** → each commission shows a standing meter with an
   **"Accept (dev)"** button (debug only, `dock_screen.gd:373`). Take one.
3. Same tab, **Quartermaster** → buy that profession's two modules.
4. **Engineering** → the Rooster has **two System slots and both are full**
   (Wayfarer Sensors + Strapdown Cargo Pod). Right-click one to unfit, then drag
   a module in.
5. **Pilot tab → loadout** → select a gem slot, click the ability to memorize it.
6. Undock, press **[1]–[5]**.

Switching profession is another "Accept (dev)" click, but each profession's
modules are `profession_lock`ed, so testing all twelve means buying each pair
under its own commission.

⚠ **Unfitting the Wayfarer Sensors** drops targeting reach to 600 (`max(600,
sensor_range)`), which shortens the 900-range targeted abilities (Timbers,
Overload, Tender Drone). Killshot is unaffected — the coilgun carries its own
2600 optics. It also greys the scan gem, since `scanner` is the tag that grants it.

## What to watch

**Energy is the biggest unknown.** A stock Rooster regenerates ~3.7/s into a 140
pool. The intent: any ONE rotation is sustainable forever; stacking two puts you
in deficit. If it feels wrong, the dial is `REGEN_BASE` in `build_ship.gd`
(2.0), not the costs.

- **Reactor pill** (on the effigy, low): white-hot blue → black. Readable?
- **Gem colours:** amber = ready · green = running · **blue = can't afford** ·
  red ✕ = module not fitted. Is "blue" legible as broke?
- **Going Dark [K]** now recharges at ×4. Does that read as a real tactical
  option, or just a pause?

**Per-ability, the things most likely to feel wrong:**

| Ability | Watch for |
|---|---|
| Crystalline Array | Cursor placement is a NEW interaction. Is placing it at range intuitive? Is radius 128 big enough to actually catch a missile? |
| Killshot | The 700 minimum + 30° cone. Does refusing to fire read as skill, or as broken? |
| Tender Drone | 30s is a long time. Can you tell it's working? |
| JINX | Evasion is invisible by nature. Can you feel a smaller hit profile at all? |
| Overload Pulse | Do you notice the shields come *back* at full strength? |
| Lance | 40°/s tracking — does it feel like aim, or like a homing missile? |

**Known gaps, deliberately not built:** AI ships use none of these (the parity
rule is unmet), weapons don't draw energy (v2), and the reactor pill has no
spend-flash animation yet.
